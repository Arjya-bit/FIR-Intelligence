# Contributing

This repository is a submission for the **IBM Bob AI Hackathon at NFSU**.

## Submission Instructions

1. Fill in all required files as specified in the template
2. Ensure `submission.yaml` has all required fields
3. Push your code and verify the GitHub Action passes
4. Submit your repo URL via the entry form before the deadline

## Repository Structure

- `submission.yaml` — Structured metadata (read by evaluators first)
- `README.md` — Project overview
- `src/` — All source code
- `docs/` — Written documentation
- `demo/` — Demo artifacts (video link, screenshots)
- `presentation/` — Slide deck

Do not delete or rename any template files.
